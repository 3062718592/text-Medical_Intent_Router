## 数据增强对照（训练集 1667 → 5157）

训练集经「中→英→中」回译扩至 5157 条（人工 1667 + 增强 3490）。**验证集 416 条全程未参与增强**，因此两类结果可直接比较。

| 方法 | 训练集 1667 | 训练集 5157 | 变化 |
|---|---|---|---|
| 规则 / 关键词 | 0.2596 / 0.2199 | 0.2596 / 0.2199 | 不变（规则不训练，兜底类同为「治疗方法」） |
| TF-IDF + SVM | 0.4423 / 0.3772 | 0.4327 / 0.3860 | 准确率 −0.96pt，Macro-F1 +0.88pt |
| BERT 微调 | 0.4784 / 0.4736 | 0.5409 / 0.4834 | 准确率 +6.25pt，Macro-F1 +0.98pt |
| Qwen3 zero-shot | 0.1779 / 0.1432 | 0.1779 / 0.1432 | 不变（零样本不训练） |
| Qwen3 LoRA SFT | 0.5865 / 0.4898 | 0.5745 / 0.5123 | 准确率 −1.20pt，Macro-F1 +2.25pt |
| Qwen3 全量微调 | 0.5481 / 0.4743 | 未运行 | — |

（单元格格式：准确率 / Macro-F1）

- 一致的趋势：数据量 3 倍后，**Macro-F1 普涨、准确率普跌**。合成样本让稀有类边界更清晰（Macro-F1 各类等权），但稀释了头部类「治疗方法」（占 22%）的判别特征，而准确率主要由它决定。
- 收益最大的是 BERT（准确率 +6.25pt）：判别式模型从同分布变体中获益最明显；LoRA 因为原本就有预训练知识，增益主要体现在小类上。
- **提升幅度仍在噪声内**：416 条验证集的 95% 置信区间约 ±4.8pt，除 BERT 准确率外均未超出。
- 增强数据的质检有必要：原始 3734 条变体中 244 条（6.5%）出现药名替换（如「乌灵胶囊→五灵胶囊」「童康片→通康片」）或数字漂移，已剔除。
- 过拟合提前：LoRA 的最优轮次从 epoch 3（1667）提前到 epoch 1（5157），说明合成样本与原句过于相似。
- 结论：**瓶颈不在数据量**。`方法` 类 recall 在三档中分别为 0.000 / 0.000 / 0.053，`定义 / 临床表现 / 治疗方法 / 方法` 四类语言线索高度重叠、占 45% 样本，下一步应合并易混类别而非继续扩数据。
